ipp-duplexd-fork

Manual duplex printing on any IPP printer — the dnf repository.

This is the package repository for ipp-duplexd-fork, a fork of ipp-duplexd adding translations and, in time, a GUI manager.

Install

sudo dnf config-manager addrepo --from-repofile=https://wraindrock.github.io/ipp-duplexd-fork/ipp-duplexd-fork.repo
sudo dnf install ipp-duplexd-fork

On dnf4 (Fedora 40 and older) use sudo dnf config-manager --add-repo with the same URL.

Upgrade

sudo dnf upgrade

Notes

  • Built in Fedora 43, Fedora 44 and Rawhide containers; each release gets the newest build.
  • Packages are unsigned, so the repository file sets gpgcheck=0.
  • Older builds are on the releases page; other distributions can use the .rpm, .deb or Arch package built there.
